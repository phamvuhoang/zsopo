# UAT Nội dung

Môi trường: staging với dữ liệu giả. Mỗi bước ghi Đạt/Không đạt, người thực hiện, thời gian, ghi chú. Không dùng dữ liệu khách thật.

| # | Bước | Kết quả mong đợi đạt | Đạt | Người/giờ |
|---|---|---|---|---|
| 1 | Soạn bài Markdown (không HTML), xem trước, gửi duyệt, đăng ngay hoặc hẹn giờ (giờ Việt Nam). | Như mô tả, không lỗi | | |
| 2 | Khôi phục phiên bản cũ tạo phiên bản mới; đổi slug bài đã đăng tạo chuyển hướng. | Như mô tả, không lỗi | | |
| 3 | Sửa chính sách/giới thiệu; bỏ dòng "Bản nháp" sau khi pháp lý duyệt. | Như mô tả, không lỗi | | |
| 4 | Tải ảnh có mô tả (alt) và chèn vào bài. | Như mô tả, không lỗi | | |
| 5 | Nhập lịch truyền thông từ CSV (không tự đăng). | Như mô tả, không lỗi | | |
| 6 | Tìm kiếm có dấu/không dấu ra đúng bài/phòng/sản phẩm. | Như mô tả, không lỗi | | |
